# Pie Chart Syntax Reference

## Keyword

```
pie
pie showData     # show data values on chart
```

## Title

```
title Chart Title
```

## Data

```
"Label" : value
"Label" : 30
"Label" : 50.5
```

Values must be positive numbers.

## Config

```
textPosition 0.5    # position of labels (0.0 to 1.0)
```
